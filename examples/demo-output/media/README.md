# Rendered media demo

These files are deterministic portfolio outputs generated locally from repository fixtures. The abstract product mark is intentionally labeled as a demo visual; it is not a real merchant photograph.

Generated with:

```bash
npm run demo:full
```

The PNGs are 1080x1080, 1080x1920, and 1200x628. The MP4 is a 20-second 1080x1920 H.264 storyboard render.

# v0.7.0 progress report

## Base re-check

v0.6.0 was treated as the base of record. Product research, campaign factory, quality gates, creative rendering, dashboard, Postman, and inactive n8n exports were preserved. No new channel was added.

## Added in v0.7.0

- append-only local project-history store
- campaign snapshot/version persistence
- research-run persistence
- persisted approvals keyed by campaign + asset
- campaign/research/approval history endpoints
- local-only Meta, Shopify, Google Ads, and email delivery adapters
- hard rejection of unsupported `live` delivery mode
- approval gating across every required channel asset
- delivery result contract with `externalWrite: false`
- delivery capabilities endpoint
- machine-readable `PROJECT-STATE.json`
- `docs/WORK-HANDOFF.md` and `docs/DECISIONS.md`
- handoff/state verification gate
- dashboard saved-history restore and persisted approval hydration
- dashboard local-delivery panel
- inline dashboard JavaScript syntax test; this caught and fixed a pre-existing escaped-newline bug

## Verification

Deterministic build-environment verification passes 52/52 automated tests. The current version still requires a fresh Windows `start-here-windows.cmd` run before claiming v0.7.0 Windows/Ollama verification; the last user-confirmed full Windows/Ollama gate was v0.3.2.

## Safety position

No adapter can activate ads, spend money, send email externally, or publish storefront changes. No n8n Cloud execution is required or recorded for this phase.

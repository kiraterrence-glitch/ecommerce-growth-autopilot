# Phase 7 Visual Polish

Phase 7 improves presentation without changing the evidence-grounded architecture.

## Improvements

- Purpose-built visual dimensions replace repeated square canvases.
- The large `SOURCE REQUIRED` state appears only in the hero.
- Benefits use compact evidence cards.
- Features use compact specification cards.
- Comparison uses multiple normalized metrics.
- Offer presentation includes explicit verification safeguards.
- Desktop vertical spacing is reduced.
- Muted text contrast is improved.
- Trust safeguards receive stronger visual treatment.
- FAQ rows use static CSS plus/minus affordances.
- Mobile layout remains responsive and browser-audited.

## Safety retained

Phase 7 does not change:

- `externalWrites=false`
- `livePublishing=false`
- human approval requirements
- evidence provenance
- comparison claim restrictions
- supplier-media rights handling
- prohibition on fabricated product photography

## Verification

After visual polish:

1. deterministic repository verification runs,
2. the dedicated visual polish audit runs,
3. real Chrome desktop/tablet/mobile QA runs,
4. screenshots are regenerated,
5. portfolio proof is re-audited.

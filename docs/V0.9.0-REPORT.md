# v0.9.0 progress report — local n8n proof hardening

## Why this release exists

v0.8.x proved the dashboard and local API. v0.9.0 closes the gap between "the n8n export looks correct" and "the exact committed workflow contract is exercised end to end before runtime import."

## Added

- deterministic `npm run n8n:contract`
- exact full-portfolio workflow graph/expression assertions
- real local API replay of research → campaign → demo status
- safety assertions for `externalWrites=false` and `livePublishing=false`
- Windows-native `127.0.0.1:3001` n8n workflow targets
- `npm run n8n:runtime-check`
- `start-local-n8n-windows.cmd`
- `import-local-n8n-workflow-windows.cmd`
- hardened `local-n8n-proof-windows.cmd`
- integration tests for the Windows-native workflow contract
- updated local n8n learning/troubleshooting documentation

## What this does not claim

The sandbox used to build this release does not contain the n8n runtime binary. Therefore `npm run n8n:contract` is a real end-to-end API/workflow-contract proof, but the final n8n-engine execution still needs to happen once on the user's local/community n8n instance.

## Safety

- no n8n Cloud execution
- no credentials in workflow exports
- no Code/Function nodes
- no external platform writes
- human approval gates preserved
